# Filmspec

CLI-инструмент для генерации спектральных изображений фильмов из видеофайлов.

#### Принцип Работы

Filmspec равномерно сэмплирует кадры из видеофайла по времени, извлекает одну линию пикселей (строку или столбец) из каждого кадра и складывает их вместе для создания уникального визуального спектра.

![example](images/example.png)

#### Режимы Сэмплирования и Компоновки

| Режим среза | Описание |
|-------------|----------|
| row | Извлечь среднюю горизонтальную линию из каждого кадра |
| col | Извлечь среднюю вертикальную линию из каждого кадра |

| Режим компоновки | Описание |
|------------------|----------|
| h | Горизонтальная укладка (слева направо) |
| v | Вертикальная укладка (сверху вниз) |

#### Требования

- Rust 1.70+
- FFmpeg (должен быть доступен в системном PATH)

#### Установка

```bash
cargo install --path .
```

#### Использование

```bash
filmspec <INPUT> [OPTIONS]
```

#### Параметры

| Параметр | Сокр. | Описание | По умолчанию |
|----------|-------|----------|--------------|
| `<INPUT>` | - | Путь к входному видеофайлу | обязательно |
| `--output` | `-o` | Путь к выходному изображению | `<имя>_spectrum.png` |
| `--width` | `-w` | Ширина выходного изображения | 1920 |
| `--height` | `-H` | Высота выходного изображения | 300 |
| `--layout` | `-l` | Направление компоновки h/v | h |
| `--slice` | `-s` | Направление среза row/col | row |

#### Примеры

```bash
# По умолчанию (1920×300, горизонтальная компоновка, срез по строкам)
filmspec movie.mp4

# Пользовательский путь и размер
filmspec movie.mp4 -o output.png -w 1280 -H 400

# Вертикальная компоновка (укладка сверху вниз)
filmspec movie.mp4 -l v

# Срез по столбцам (извлечение вертикальных линий пикселей)
filmspec movie.mp4 -s col
```
